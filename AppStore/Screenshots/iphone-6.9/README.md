# iPhone screenshots

The five English screenshots in `en-US/` are the redesigned App Store set for RHOIDS. Each image is 1320 × 2868 pixels, opaque RGB, with an sRGB profile. Filenames specify the display order. `manifest.json` records their SHA-256 checksums.

Version 1.1.4 is live with an earlier five-image set (`OnTime`, `AutoUnlock`, `BlockCategories`, `Research`, `PrivateHistory`). Apple locks the screenshots of a released version, so this set is attached to the 1.1.5 draft in App Store Connect and goes live when 1.1.5 is released. It was uploaded on November 20, 2026, and the stored images match these files pixel for pixel.

Every phone uses a real app capture inside Apple's official iPhone 17 Pro Max bezel. The captions and the layout are marketing artwork. The captures show the Science hub from 1.1.4.

These marketing assets do not establish current-build or physical-device verification. Raw captures, rendering tools and upload logs are kept outside the public repository.
